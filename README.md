# 🤖 Personal Assistant CLI

Персональний помічник з інтерфейсом командного рядка. Управління контактами та нотатками з автоматичним збереженням даних.

---

---

## ✨ Функціонал

- ✅ Управління контактами (додавання, редагування, видалення, пошук)
- ✅ Управління нотатками (додавання, редагування, видалення, пошук)
- ✅ Система тегів для нотаток
- ✅ Пошук по текстам та тегам
- ✅ Автоматичне збереження даних на диск
- ✅ Валідація даних (телефон, email, дата)

---

## 📖 Команди

### Загальні

```
hello              - Привіт
help               - Показати довідку
exit / close      - Вихід та збереження
```

### 📒 Контакти

```
add <name> <phone>                              - Додати контакт
change <name> <old_phone> <new_phone>          - Змінити телефон
phone <name>                                    - Показати контакт
all                                             - Показати всі контакти
delete <name>                                   - Видалити контакт

add-birthday <name> <DD.MM.YYYY>               - Додати день народження
show-birthday <name>                            - Показати день народження
birthdays <days>                                - Дні народження на N днів
add-email <name> <email>                        - Додати email
add-address <name> <city>, <street>, <house>   - Додати адресу
```

### 📝 Нотатки

```
add-note <title> | <text>                      - Додати нотатку
edit-note <ID> | <text>                        - Редагувати текст
edit-note <ID> -title <title>                  - Редагувати назву
delete-note <ID>                               - Видалити нотатку

search-note <query>                            - Пошук по тексту
search-tag <tag>                               - Пошук по тегу

add-tag <ID> <tag>                             - Додати тег
remove-tag <ID> <tag>                          - Видалити тег

all-notes                                      - Показати всі нотатки
all-tags                                       - Показати всі теги
```

## 📦 Технології

- **Python 3.10+** — основна мова
- **pickle** — збереження даних
- **re** — регулярні вирази для валідації
- **datetime** — робота з датами та часом
- **collections.UserDict** — для реалізації колекцій

---

## 📋 Валідація

### Телефон

- Формат: `380XXXXXXXXX` (12 цифр, починаючи з 380)
- Приклад: `380501234567`

### Email

- Формат: `user@domain.com`
- Приклад: `john@example.com`

### День народження

- Формат: `DD.MM.YYYY`
- Приклад: `15.03.1990`

### Адреса

- Формат: `<city>, <street>, <house>[, <apartment>]`
- Приклад: `Київ, Хрещатик, 1, 5`

---

## 💾 Збереження даних

Дані зберігаються автоматично при виході з програми у файли:

- `addressbook.pkl` — контакти
- `notesbook.pkl` — нотатки

Файли розташовуються у теці, де знаходиться `main.py`.
